# P158 campus progress snapshot — 25 October 2026

Latest accepted P158 working scene, including the current roof work and environment; 279 Jacaranda tree instances retained.

This is a new progress snapshot of an independent personal campus reconstruction. Earlier releases and the original working scenes remain preserved. It does not claim completed campus coverage or institutional endorsement.

## Files and changes

- Editable Blender scene with packed dependencies; source exclusions and private paths were checked in the public copy.
- Fresh portable GLB from that scene. The first export changed broad grass from green to brown; materialfix1 corrects the colour recipes. The rejected export is not included.
- Actual Blender, corrected GLB and near-contact previews, plus current and base mapped data, provenance and licence notices.

## Checks on 25 October 2026

- Saved public Blender file reopened; protected geometry and source-file preservation checked.
- Packed-image dependencies resolved; public metadata and GLB external references checked.
- Sixty ordered SOLID overview frames inspected for the source scene.
- Two near-contact sites in the public Blender copy, three changing Material Preview frames per site, inspected for visible gaps or switching patches.
- Corrected GLB imported into a fresh scene. Its bounds matched the Blender scene (maximum difference 0 m), no missing images were found, and actual same-camera previews were inspected.

These are sampled checks, not proof of every intersection, every viewing range, GLB near-contact behaviour or real-time frame rate. Incomplete/context geometry and inferred details remain. Ground and elevations are schematic or inferred; this is not surveyed terrain. Blender material graphs remain editable; GLB shader equivalence is not exact. These are large desktop assets; loading performance has not been benchmarked.
